# Code of Conduct

Participation must be respectful, constructive, inclusive, and focused on improving the project.

Harassment, discrimination, threats, doxxing, sexualized conduct, personal attacks, and deliberate disruption are not accepted.

Report conduct concerns privately to maintainers. Maintainers may edit or remove content, issue warnings, restrict participation, or permanently ban participants based on severity and pattern.

This policy applies in project spaces and when someone publicly represents the project.
