# Concepts

## Skill

A self-contained directory that teaches a repeatable workflow. It combines discovery metadata, instructions, references, evaluations, and optional resources.

## Trigger

The circumstances in which an agent or human should select a skill. Trigger information belongs in the frontmatter description.

## Artifact

A reviewable output required by a skill: specification, schema, state machine, decision record, test matrix, migration plan, runbook, or report.

## Quality gate

Evidence that must exist before work is considered complete.

## Evaluation

A realistic task and observable expectations used to test whether the skill improves outcomes.

## Bundle

A curated list of independent skills for a common product stage. Bundles do not merge or rewrite skill content.

## Progressive disclosure

Load metadata for discovery, the main body for execution, and deeper references only when required.

## Runtime-agnostic

The skill source does not require an application runtime, framework, language, package manager, database, cloud, or AI provider.
