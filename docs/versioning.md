# Versioning

The repository and individual skills follow Semantic Versioning.

## Skill changes

- Patch: editorial clarification or evaluation addition without behavior incompatibility.
- Minor: new optional workflow, artifact, reference, or compatibility.
- Major: removed behavior, changed required output, changed safety assumptions, or incompatible contract.

## Deprecation

Deprecated skills remain discoverable for at least one minor release and identify their replacement. Security removals may be immediate.

## Generated catalogs

Catalog format versions are independent of repository and skill versions.
