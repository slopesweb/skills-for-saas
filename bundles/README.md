# Curated Bundles

Bundles are runtime-neutral JSON lists. They do not copy or merge skill content.

## MVP Foundation

The minimum serious foundation for a launchable multi-tenant SaaS.

## AI SaaS

AI feature contracts, model providers, prompts, RAG, agents, evaluations, governance, metering, privacy, and observability.

## Enterprise SaaS

Stronger tenant isolation, identity, lifecycle, data governance, compliance, reliability, incident response, and recovery.

Consumers may create their own bundles by referencing skill names from `catalog/skills.json`.
