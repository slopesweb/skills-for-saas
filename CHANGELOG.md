# Changelog

All notable changes follow Keep a Changelog and Semantic Versioning.

## [0.1.0-alpha.1] - 2026-07-22

### Changed

- Rebuilt the repository as a runtime-agnostic, agent-neutral skill library.
- Removed all required Node.js, Bun, Deno, package-manager, and JavaScript tooling.
- Replaced the previous CLI with a declarative catalog and optional Python standard-library maintenance tools.
- Rewrote the public documentation in English.
- Rebuilt the README for a stronger GitHub presentation.
- Removed the repository's internal `PROJECT_CONTEXT.md` from the public source tree.
- Updated compatibility language across the complete catalog.
- Updated GitHub Actions to current official action generations and least-privilege permissions.

### Added

- Spec-driven development skill.
- Repository architecture skill.
- Extension and plugin architecture skill.
- Audit logging skill.
- Cost governance and FinOps skill.
- Public format specification.
- Repository-neutral examples and authoring templates.
- Machine-readable category, skill, and bundle catalogs.
- Optional release packaging with deterministic checksums.

## [0.1.0-alpha.0] - 2026-07-22

### Added

- Initial experimental catalog and repository baseline.
