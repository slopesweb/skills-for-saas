# Testing Skills

- [`contract-testing`](./contract-testing/SKILL.md) — Verify API, event, provider, and module compatibility independently of full-system environments.
- [`multi-tenant-security-testing`](./multi-tenant-security-testing/SKILL.md) — Prove requests, jobs, caches, exports, search, files, analytics, and admin paths cannot leak across tenants.
- [`performance-load-testing`](./performance-load-testing/SKILL.md) — Measure capacity, latency, fairness, and failure behavior under realistic multi-tenant workloads.
- [`test-strategy`](./test-strategy/SKILL.md) — Create a risk-based test strategy spanning unit, integration, contract, end-to-end, performance, migration, and resilience.
