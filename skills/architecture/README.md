# Architecture Skills

- [`domain-modeling`](./domain-modeling/SKILL.md) — Model SaaS domains around business language, invariants, aggregates, commands, events, and policies.
- [`modular-monolith-design`](./modular-monolith-design/SKILL.md) — Design a deployable monolith with enforceable domain boundaries and a credible path to selective extraction.
- [`scalability-planning`](./scalability-planning/SKILL.md) — Create an evidence-based scaling plan for SaaS workloads without premature distributed complexity.
- [`service-boundary-design`](./service-boundary-design/SKILL.md) — Evaluate and define service boundaries using domain ownership, scaling pressure, reliability, and team autonomy.
