# Security Skills

- [`audit-logging`](./audit-logging/SKILL.md) — Design immutable, tenant-aware audit records for sensitive actions, administrative access, policy decisions, and security investigations.
- [`privacy-compliance`](./privacy-compliance/SKILL.md) — Translate privacy and compliance obligations into concrete data, access, retention, audit, and evidence controls.
- [`secrets-key-management`](./secrets-key-management/SKILL.md) — Manage application secrets, tenant credentials, encryption keys, rotation, and emergency revocation.
- [`threat-modeling`](./threat-modeling/SKILL.md) — Identify assets, actors, trust boundaries, abuse cases, controls, and residual risks before implementation.
