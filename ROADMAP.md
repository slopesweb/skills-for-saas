# Roadmap

## Alpha: prove the system

- Validate the catalog in real SaaS repositories.
- Improve skill triggering descriptions and negative evaluations.
- Establish public compatibility tests for major agent environments.
- Add contributor provenance and review ownership.
- Publish documentation as a static site without changing the source format.

## Beta: composition and trust

- Define bundle composition and conflict rules.
- Add cross-skill evaluation suites.
- Add signed release manifests and reproducible package verification.
- Introduce maturity and trust levels for community skills.
- Add domain packs for fintech, legal, healthcare, marketplaces, and developer platforms without weakening the core.

## 1.0: stable open standard

- Freeze the stable frontmatter and catalog schemas.
- Publish migration guarantees.
- Certify the core skill set.
- Formalize maintainer working groups.
- Provide public benchmark and compatibility reports.
